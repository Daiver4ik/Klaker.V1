# Klaker.V1
Klaker is a simple soundpad for Windows. Drag in your sounds, give each one a hotkey, and play them in Discord, games, or streams. It keeps working in the background when the window is closed.
КАК ЗАПУСТИТЬ KlakerPad:

1. Распакуй архив целиком (например достань папку с архива, и закинь на рабочий стол).
2. Убедись, что на компе установлен Python (при установке Python должна быть включена галка "Add Python to PATH").
3. Запусти файл `start.bat`.
4. Очень важно! Для того что бы звук(аудио) шел в микрофон, нужно скачать vb-audio virtual cable.

ЧТО ДЕЛАТЬ ЕЩЁ:
- Если пишет, что нет Python — устанавливай его.
- Если вылетает ModuleNotFoundError — значит, распаковал архив не полностью или потерял какой то файл
